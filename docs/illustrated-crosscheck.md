A confirmed name means that the selected edition contains that posture or the explicitly described variant. It does not establish the app's movement as identical. Ladder membership and ladder ordering are separate claims: this index establishes membership, while the notes' teaching progressions are not reproduced as such in the source.

“Differs” identifies a measurable difference, including edition numbering. “Not in this edition” means the claimed item or relationship cannot be established from this selection; it is not a finding that the original note is wrong. Missing reference fields make no numerical claim.

The compound note for head-to-knee/stretching contains one difficulty value, 6. This matches Paschimottanasana, while Janu Sirsasana carries 5 in the illustrated edition. That distinction is reported without changing the note.

The Marichi numbering is internally inconsistent: the heading and photograph table use II, but the subsequent Matsyendra discussion uses III for the same entry. The index retains II and records the inconsistency.

Photograph substitutions are editorial comparisons. In particular, the map uses a reclining analogue for standing head-to-knee, a shoulderstand preparation for wind-removing, and a seated endpoint for the sit-up. Their notes delimit what those images can establish.
